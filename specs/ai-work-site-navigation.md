# AI直聘站点导航与路由职责

> **文档状态**：当前实现约束
> **适用范围**：TanStack Start Web 站点的首页、AI 员工目录、桌面客户端下载页，以及公共导航与页脚

## 目标

将产品介绍、员工发现和客户端获取拆成独立站内入口，避免首页同时承担完整目录、下载落地页和锚点跳转容器的职责。

这是一项 Web 信息架构约束，不改变 `clawhub` / `clawdhub` CLI、公开 API、发现协议、Convex 数据层或桌面端业务契约。

## 路由职责

| 路径              | 页面职责         | 必须包含                                                 | 不应包含                                   |
| ----------------- | ---------------- | -------------------------------------------------------- | ------------------------------------------ |
| `/`               | AI直聘产品首页   | 平台价值、核心能力、进入招聘或下载的引导                 | 完整 AI 员工目录、招聘目录分页与筛选状态   |
| `/recruit-ai`     | AI 员工目录      | 搜索、分类、分页加载、员工选择及进入桌面端继续招聘的引导 | 首页营销区块、客户端下载页的完整内容       |
| `/desktop-client` | 桌面客户端落地页 | 客户端用途、Windows/macOS/Linux 的站内安装包入口         | 员工目录列表、外部发布页链接和安装步骤模块 |

`/#recruit-ai` 是历史锚点，不再作为主导航、页脚或页面间跳转的目标。新链接必须使用 `/recruit-ai`。

## 公共导航约束

公共导航和页脚的产品入口必须始终指向站内路由：

| 文案         | 目标              |
| ------------ | ----------------- |
| 首页         | `/`               |
| 招聘 AI 员工 | `/recruit-ai`     |
| 客户端下载   | `/desktop-client` |

下载入口不应直接替代导航路由为第三方地址。用户先进入 `/desktop-client`，再从该页选择具体安装包。所有客户端安装包必须使用当前站点下的 `/downloads/desktop/<platform>/<variant>` 路径，不得从下载按钮跳转到 GitHub Releases 或其他外部发布页。

当前下载路径契约：

- Windows：`windows/x64`、`windows/x86`
- macOS：`macos/arm64`（Apple 芯片）、`macos/x64`（Intel）
- Linux：`linux/appimage-x64`、`linux/appimage-arm64`、`linux/deb-x64`、`linux/deb-arm64`、`linux/rpm-x64`、`linux/rpm-arm64`

站点部署层必须将这些稳定路径映射到对应安装包；页面不得耦合带版本号的实际文件名。

## AI 员工目录的数据边界

`/recruit-ai` 使用版本控制中的 `src/content/experts.json` 作为静态岗位目录快照；该快照由桌面端维护的岗位目录同步而来。

- Web 目录只负责发现与选择；员工实际招聘、面试、团队组织与工作流执行仍在桌面客户端完成。
- 目录检索、分类与“加载更多”在前端基于已加载静态目录执行，不新增服务端查询、Convex 订阅、轮询或常驻进程。
- 员工卡片的选择操作必须保留“继续到客户端招聘”的交互契约；不得将其改造成未定义的 Web 端招聘写入流程。
- 桌面端岗位库的字段或来源变更时，应同步更新 `src/content/experts.json`、检查 `RecruitAiDirectory` 的映射与本说明，避免两个产品入口展示不同的角色集合。

## 生产浏览器冒烟契约

生产部署的匿名浏览器冒烟只验证 AI直聘当前公开流程，不依赖登录态、发布权限或旧技能市场文案：

- `/recruit-ai` 能渲染目录、搜索岗位、按分类筛选，并能显示空结果。
- 首页公共导航可进入 `/recruit-ai` 与 `/desktop-client`。
- `/desktop-client` 展示 Windows、macOS 和 Linux 的站内下载入口，所有链接均以 `/downloads/desktop/` 开头。
- 测试不得等待已移除的 `data-clawhub-hydrated` 标记，也不得将 `/upload`、`/import`、`/skills` 的旧发布流程作为 AI直聘发布门槛。

## 维护准则

1. 新增首页模块时，先判断它是否属于产品介绍；若主要服务于岗位检索，应归入 `/recruit-ai`。
2. 新增客户端安装、系统要求或发行说明时，归入 `/desktop-client`；首页仅保留入口性说明。
3. 公共导航配置与页脚必须共享同一组路由语义，避免 Header、Footer、移动菜单再次出现锚点或外链分叉。
4. 路由树由 TanStack generator 生成；新增或变更文件路由后更新 `src/routeTree.gen.ts`，不要手工编辑生成内容。
5. 任何将目录改为在线数据源的方案，必须先明确缓存、失败降级、请求成本和是否需要实时性；默认继续使用静态桌面端角色库。
